# 情報整理・学習ノート作成ルール

本プロジェクトでは、試験対策やドキュメント整理において以下の規則を厳守します。

## 1. 推測による内容補足・追加の禁止（絶対遵守）
- 推測、外部知識、一般的なAI仕様からの先回りによる内容の補足や追加は一切禁止します。
- ユーザーが間違った内容を学習してしまうことを防ぐため、必ずユーザーから提供された正確な情報（公式教材のテキスト、スライド、問題文など）のみを元に整理・記録してください。
- 提供された情報に含まれていない項目、数値、仕様などを勝手に推測して記載してはなりません。

## 2. 忠実な情報整理
- 提供された情報の構造、目次、用語、文脈を忠実に反映して整理してください。
- 不明な点や補足が必要と思われる点がある場合でも勝手に書き足さず、ユーザーに確認または情報提供を依頼してください。

## 3. ファイル整理の手順（貼付用ファイル運用）
- ユーザーは教材からコピーしたテキストを各モジュール直下の `教材テキスト貼付用.md` にそのまま貼り付けます。
- エージェントは、そこに書かれた情報だけを元に（推測や勝手な付け足しなしで）トピックや目次を判別し、対応する各ファイル（例: `01_モジュール概要.md`、`02_LLMの振る舞い.md` など）に構造化されたマークダウンとして反映します。
- 整理が完了した内容は、`教材テキスト貼付用.md` から削除（または整理完了分を取り除いてクリア）します。各整理先ファイルには不要なマーカー行を置かず、綺麗な状態を保ちます。
## 4. ファイルパスの表記規則（絶対パス禁止・相対パス厳守）
- ドキュメント内やチャット応答においてファイルパスを記述する際は、**必ず相対パス**で記述してください。
- 絶対パス（`/Users/...` など）は一切使用してはなりません。
- Markdownリンクを記述する場合も、相対パス（例: `./01_モジュール概要.md` など）を使用してください。
