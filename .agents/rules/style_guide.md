# 記述スタイルガイド

本プロジェクトでは、すべてのドキュメント作成および回答において以下の規則を厳守します。

## 1. 絵文字の禁止
- 絵文字（Unicode絵文字、装飾記号等）は一切使用しないこと。
- 見出し、リスト、表、ステータス表示など、あらゆる場所で絵文字を使用しないこと。

## 2. 自然な日本語の使用
- 人間が作成した実務文書のような、簡潔で自然な日本語を使用すること。
- AI特有の言い回し、誇張表現、定型文を避けること。
  - 避ける例：「〜と言えるでしょう」「〜に寄与します」「〜を網羅」「〜マインドセット」「〜5大原則」「重点攻略」「NG」など
- 造語や一般的ではない略語を使用しないこと。公式ドキュメントで定義されている正式名称や一般的な用語を用いること。
