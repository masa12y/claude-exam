# 本番品質のプロンプティング、エージェント、ツールユース

Claudeを使うコードを書くことと、Claudeにコードを書かせることは、まったく別の作業です。本モジュールでは、ツールスキーマ、コンテキスト管理、エージェントループなど、基本的な対話利用を超えるすべての領域を扱い、Claudeをプログラム的に統合し、出力処理の信頼性を確保し、堅牢な本番ソリューションをデプロイできるようにします。
