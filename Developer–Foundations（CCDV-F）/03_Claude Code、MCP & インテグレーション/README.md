# Claude Code、MCP & インテグレーション

これまでのモジュールでは、プロンプト、ツールスキーマ、コンテキストエンジニアリング、エージェントループ、マルチモーダル入力といった、APIの基本的な構成要素を扱ってきました。このモジュールは、その基礎の上に直接構築されています。Claude Codeを使うと、同じモデルをターミナル環境内で操作できるようになり、パーミッション層、設定システム、チーム向けの共有機能が導入されます。MCPプロトコルにより、外部サービスとの安全な統合が可能になります。このモジュールでは、堅牢なセキュリティと効果的な展開のために、Claude CodeとMCPを設定する方法を学びます。
